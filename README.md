# Using AI Without Outsourcing Your Thinking

**Research + AI · A Guide for Humanities Students**

A single-page teaching guide for a library instruction session in *Introduction to Storytelling Across Cultures*, Shannon Library, University of Virginia. It works as a reading page students can scroll on their own, and as a clicker-driven slide deck for the live session.

The central question: **when does AI support your thinking, and when does it replace it?**

## How to use it

Open `index.html` in any modern browser. There is no build step and nothing to install.

**Reading view (default).** Scroll the page. Each screen builds itself as it comes into view. Use **Contents** to jump to a part, and **Motion on/off** to turn the animation off.

**Present mode.** Press **Present ▸** (or open the page with `#present`). The page becomes a 16:9 deck where every clicker press shows one change.

| Key | Action |
|---|---|
| → · Page Down · Space | Next beat (clicker forward) |
| ← · Page Up | Back one beat |
| T | Start / stop the activity timer on this screen |
| 1–8 | Jump to Part 1–8 |
| R | Show the rest of this screen at once |
| O | Include / skip the "if time remains" screens |
| C | Session plan: jump to any screen |
| B · . | Blank the screen |
| F · F5 | Full screen |
| M | Motion on/off |
| X | Leave presenter view |

Page Up and Page Down work even inside a text box, so the clicker never gets stuck. A reload returns to the same screen and beat. Checklist ticks and exit-ticket answers are saved in the browser only; nothing is sent anywhere.

## Design

Night-sky design shared with the *Research Lifecycle* site: slate background with drifting nebula and twinkling stars, Fraunces / Spectral / JetBrains Mono type, gold accents, cyan for AI. Elements rise into view as you scroll, and cards glow where the pointer rests. The page respects the system "reduce motion" setting and prints cleanly.
